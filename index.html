Convert and export a file

  1. Tap Import STL File and select an ASCII or binary STL from Files.
  2. Preview the mesh, choose STEP, and tap Convert to STEP.
  3. On the result screen, tap Save to Files or Share. The export follows the mesh facets and does not reconstruct the original CAD design history.

Pro and tips

Free single-file STEP conversion is available for meshes up to 50,000 triangles after optional simplification. Pro is a one-time purchase for IGES export, batch conversion, and larger meshes. Device and input limits still apply.

To recover Pro, open Settings → Restore Purchases with the Apple Account used to buy it. An optional tip under Settings → Support Development does not change features or limits and cannot be restored.

如需 iPhone 或 iPad 版帮助，请联系开发者 Bo Zhang / ZizWorks：1363555264@qq.com。

转换并导出文件

  1. 点「导入 STL 文件」，从「文件」中选择 ASCII 或二进制 STL。
  2. 预览网格、选择 STEP，并点「转换为 STEP」。
  3. 在结果页点「存到“文件”」或「分享」。输出保留网格分面，不会重建原始 CAD 设计历史。

Pro 与自愿打赏

免费版可逐个转换至 STEP，可选减面后三角面不超过 50,000。一次性买断 Pro 可导出 IGES、批量转换及处理更大的网格，仍受设备和输入条件限制。

用原购买所用的 Apple 账户在「设置 → 恢复购买」恢复 Pro。「设置 → 支持开发」的自愿打赏不会增加功能或转换额度，打赏也不可恢复。
